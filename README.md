# 🤖 SuguChatBot Live News

**SuguChatBot Live News** is a modern WhatsApp-style AI News web application that delivers the latest news in a simple chat interface. Users can read news in **English 🇬🇧** and **தமிழ் 🇮🇳** with a clean, mobile-friendly experience.

# 📦 Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/SuguChatBot-Live-News.git
```

Open the project folder:

```bash
cd SuguChatBot-Live-News
```

Open **index.html** in your browser.

---

# 🌐 Deployment

This project can be deployed easily using **GitHub Pages**.

1. Push the project to GitHub.
2. Open **Settings**.
3. Select **Pages**.
4. Choose the **main** branch.
5. Save the settings.
6. Your website will be published.
